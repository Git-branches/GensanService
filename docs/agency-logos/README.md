# Agency logos

Original logo files for the agencies listed on Andam GenSan. The site does not load these files; it shows
the copies uploaded in the admin panel, which are saved in `backend/public/uploads/` (not tracked by git).

After setting up a new server, upload each logo again from **Admin → Agencies → Edit → Upload logo**.
PNG, JPG, and WebP are accepted (up to 2 MB). The uploader does not accept SVG, so use `philhealth.png`
for PhilHealth.

The logos belong to their agencies and are used only to identify them.
